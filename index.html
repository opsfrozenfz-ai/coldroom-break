Cloud Backend & Historical Center

ศูนย์จัดการฐานข้อมูลหลังบ้าน & สรุปข้อมูลย้อนหลังรายวัน

ระบบบันทึกข้อมูลการสแกนทุกครั้งขึ้นฐานข้อมูลคลาวด์อัตโนมัติ พร้อมผูกป้ายกำกับวันที่ (YYYY-MM-DD) เพื่อเรียกดูย้อนหลังได้ตลอดเวลา

1 ขั้นตอนบันทึกอัตโนมัติ (Auto-Save)

ทุกครั้งที่พนักงานสแกนเริ่มพักหรือสแกนกลับเข้าห้องเย็น ระบบจะบันทึกเวลาเข้า-ออก โซน และคำนวณเวลาจริงลง Cloud Firestore ทันทีโดยไม่ต้องกดเซฟเอง

2 แยกเก็บรายวัน (Daily Indexing)

ข้อมูลทุกแถวจะถูกประทับรหัสวันที่ (dateKey: YYYY-MM-DD) และเก็บประวัติชั่วโมง OT ของแต่ละวันแยกกัน ทำให้ดูย้อนหลังได้แม่นยำ

3 การเรียกดูข้อมูลย้อนหลัง

กดเลือกวันที่จากปุ่มลัด (วันนี้ / เมื่อวาน / 2 วันก่อน) หรือเลือกจากปฏิทินในแท็บที่ 2 และแท็บที่ 3 หรือคลิกจากตารางสรุปรายวันด้านล่างได้เลย

4 ส่งออกรายงานฝ่ายบุคคล (HR/QC)

สามารถส่งออกเป็นไฟล์ Excel (CSV) แยกตามวันที่เลือก หรือดาวน์โหลดไฟล์สำรองฐานข้อมูลหลังบ้านทั้งหมด (Full JSON Backup) เก็บเข้าเซิร์ฟเวอร์บริษัท

Google Sheets + Apps Script API

เชื่อมต่อฐานข้อมูลเข้ากับ Google Sheets แบบเรียลไทม์

บันทึกทุกการยิงสแกนบาร์โค้ด (`Code_128`), สรุปโควตารายบุคคล และรายชื่อพนักงานเข้าสู่ไฟล์ Google Sheets ของคุณโดยอัตโนมัติ (แยกแผ่นงาน `Break_Logs`, `Daily_Quota`, `Employees`)

คำสั่งซิงค์ข้อมูลกับ Google Sheets ด้วยตนเอง: ยังไม่ได้ใส่ URL
สถานะล่าสุด: รอการตั้งค่า Web App URL...

ขั้นตอนการติดตั้งโค้ดใน Google Sheets (ใช้เวลาเพียง 1 นาที)

โค้ดนี้จะสร้างแผ่นงาน (Sheet Tab) ให้เองอัตโนมัติ 3 แผ่น: Break_Logs, Daily_Quota และ Employees

1. เปิดไฟล์ Google Sheets

สร้างไฟล์ Google Sheets ใหม่ แล้วไปที่เมนูด้านบน ส่วนขยาย (Extensions) → Apps Script

2. วางโค้ด `Code.gs` ด้านล่าง

ลบโค้ดเดิมในหน้าจอ Apps Script ออกทั้งหมด แล้วกดปุ่ม คัดลอกโค้ด ด้านบนไปวางแทนที่ จากนั้นกดบันทึก (💾)

3. กดการทำให้ใช้งานได้ (Deploy)

คลิกปุ่ม การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ เลือกประเภทเป็น เว็บแอป (Web App) และตั้งค่าผู้มีสิทธิ์เข้าถึงเป็น "ทุกคน (Anyone)"

4. คัดลอก URL มาวางในแอป

คัดลอก Web App URL (`.../exec`) มาวางในช่องด้านบน แล้วกดปุ่ม บันทึก URL เป็นอันเสร็จสมบูรณ์!
